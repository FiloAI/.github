# FiloMail — Never Miss What Matters

An AI-powered email client designed for Gmail.

Long threads become clear takeaways. Important tasks surface automatically. Smart labels keep your inbox organized — so you can focus on what truly matters.

### Core Features

- **Auto Summary** — Long email threads condensed into clear takeaways
- **To-Do Extraction** — Turn emails into simple tasks with one click
- **Smart Labels** — User-defined labels powered by AI that automatically file new messages
- **Smart Reply** — Craft replies instantly with AI that adapts to your style
- **Translation** — Fast, accurate translations that read naturally
- **Smart Filtering** — Automated categorization, priority detection and noise-free filtering
